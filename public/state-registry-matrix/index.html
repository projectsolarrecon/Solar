State Registry Matrix

A decision-level comparison of how state registry systems affect housing, public exposure, risk-based differentiation, reporting burden, and the possibility of reduced restrictions over time.

Prototype · Florida / Oregon / Tennessee

How to read this prototype

The descriptive value and the judgment about that value are intentionally separate. A state can have high risk responsiveness, which is generally favorable, while also having high public exposure, which is generally unfavorable. Conditional access to a better outcome still counts as structurally favorable when the law creates a real path to it.
